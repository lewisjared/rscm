Moved MAGICC7 preparation that depends on parameters from `from_magicc7` into the components,
so a parameter changed on a built spec or configuration takes effect without translating again.

- `ClimateUDEB`'s `subannual_forcing` gained `regional_pattern_years` and `initial_erf_2xco2`.
  It derives the regional pattern from the scaled forcing and, when `internal_efficacy` is unset,
  the first-years internal efficacy from LAMCALC.
  `rscm.magicc.prescribed.volcanic_pattern` and `rscm.magicc.prescribed.solar` were removed.
- `ClimateUDEB`'s `upwelling_threshold_temperature_sh` is optional,
  and follows the northern threshold when unset.
- `ForcingAgent` gained `scale`, a factor on the input before the efficacy.
  `from_magicc7` sets it to `rf_solar_scale` for solar forcing,
  so the `Effective Radiative Forcing|Solar` input is now unscaled.
  Solar inputs saved from an older `from_magicc7` are already scaled and would be scaled twice,
  so regenerate them.
- `CH4Oxidation` takes `soil_lifetime`, `stratospheric_lifetime` and `tropospheric_cl_lifetime`
  in place of `non_oh_lifetime`.
  `HalocarbonChemistry` takes `initial_ch4_lifetime` and the three `ch4_*_lifetime` parameters
  in place of `initial_ch4_oh_lifetime`.
- `CH4OxidationBuilder.initial_values` gives the initial CH4 burdens,
  which `rscm.magicc.model.setup` uses unless the configuration sets them.
  Configured fossil, biosphere or permafrost burdens are taken out of the natural burden.
- `TerrestrialCarbon` gained `include_temperature_feedback`, which `co2_tempfeedback_switch` sets.
- Feedback start years outside the run are no longer moved into it,
  because the components already treat them as the run's first or last year.
