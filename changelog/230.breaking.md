With a schema, every modelled variable is stored and returned in the schema's unit.
Results for a variable whose producer declares another unit, such as `kW/m^2` under a `W/m^2` schema, now come out converted and labelled with the schema unit.

Each variable now holds a single initial value.
The latest of `with_initial_values` and `with_initial_grid_values` for a name wins,
where before grid values always took precedence over a uniform value.
